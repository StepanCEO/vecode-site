Задача

Площадка для лизинга авто и спецтехники: каталог, расчёт платежа по условиям банков в каждой карточке и заявка в лизинг. Заказчик попросил наполнять каталог автоматически — с сайтов лизинговых компаний — и выгружать фид для Яндекса.

Что сделали

  1. Каждую ночь робот обходит сайты 8 лизинговых компаний: добавляет новые объявления с фото, обновляет цены, убирает снятые с продажи.
  2. К каждой карточке нейросеть пишет уникальное описание.
  3. Фильтр в три уровня — тип, подтип и вариант вроде «самосвал 6×4». Каждая комбинация стала отдельной страницей с понятным адресом.
  4. Платёж каждого банка — прямо в карточке техники, от выгодного предложения к дорогому.
  5. Лента «Ищут авто»: запросы на технику из почтовых рассылок брокеров. Система скрывает телефоны и почты и подбирает под запрос машины из каталога, понимая сленг вроде «трал» и «реф».
  6. Карта сайта, фид для Яндекса и микроразметка. Интерфейс сделан как мобильное приложение.

Что изменилось для клиента

  • Техника лизинговых компаний подтягивается каждую ночь — каталог пополняется без ручного ввода.
  • Вместо одной страницы каталога — 388 страниц фильтра, каждую из которых поисковики могут показать по своему запросу.
  • Запросы, которые годами копились в почтовых рассылках, превратились в ленту с подбором техники.
